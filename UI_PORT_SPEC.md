# Задача: перенести раскладку Telegram Android в мобильное приложение

## Что есть

React Native приложение (Expo 55, RN 0.83, React 19), исходники в `mobile/`.

```
mobile/App.tsx          1512 строк — ВСЯ логика и весь текущий UI в одном файле
mobile/src/theme.ts     палитра и метрики Telegram (уже написана, точные значения)
mobile/src/api.ts       сетевой слой          — НЕ ТРОГАТЬ
mobile/src/types.ts     типы Message/Room/User — НЕ ТРОГАТЬ
mobile/src/storage.ts   AsyncStorage           — НЕ ТРОГАТЬ
mobile/src/crypto.ts    E2E (заглушка)         — НЕ ТРОГАТЬ
mobile/src/roomCrypto.ts шифрование комнаты    — НЕ ТРОГАТЬ
mobile/src/webrtc.ts    звонки                 — НЕ ТРОГАТЬ
mobile/src/notifications.ts пуши (заглушка)    — НЕ ТРОГАТЬ
mobile/src/config.ts    адреса                 — НЕ ТРОГАТЬ
mobile/src/format.ts    displayName/roomTitle/roomPreview/shortTime — НЕ ТРОГАТЬ
```

## Цель

Сделать так, чтобы приложение выглядело и компоновалось **как Telegram Android**.
Переносится расположение элементов, размеры, цвета и шрифты. Функциональность
не меняется.

Значения цветов и размеров брать **только** из `mobile/src/theme.ts`.
Ничего не выдумывать, не подбирать на глаз, не хардкодить свои hex.

## Что создать

Разбить UI на компоненты и экраны. Логику оставить в `App.tsx`.

```
mobile/src/components/Avatar.tsx        круглый аватар, цвет из avatarColorFor(id)
mobile/src/components/ChatListItem.tsx  строка списка чатов
mobile/src/components/MessageBubble.tsx пузырь сообщения
mobile/src/components/DatePill.tsx      плашка «Сегодня» / «12 октября»
mobile/src/components/ChatHeader.tsx    шапка экрана чата
mobile/src/components/Composer.tsx      панель ввода
mobile/src/components/MainHeader.tsx    шапка списка чатов
mobile/src/screens/AuthScreen.tsx       вход/регистрация
mobile/src/screens/ChatListScreen.tsx   список чатов
mobile/src/screens/ChatScreen.tsx       переписка
mobile/src/screens/ProfileScreen.tsx    профиль (сейчас модалка внутри App.tsx)
```

`App.tsx` переписать так, чтобы он **остался владельцем всего состояния**:
все `useState`, `useEffect`, `useRef`, обработчики (openRoom, doSend, submitAuth,
logout, playVoice, startCall, reactions, uploads, профиль, сессии, выход) сохранить
дословно. Меняется только JSX и стили: вместо инлайновой разметки — вызовы новых
компонентов, а пропсы им передаются те же, что сейчас используются.

## Раскладка: что где должно стоять

### Экран списка чатов

```
┌──────────────────────────────────────────┐
│ 67                    [🔍]         56dp  │  шапка, actionBar
├──────────────────────────────────────────┤
│ [🔍 Поиск]                               │  поле поиска под шапкой
├──────────────────────────────────────────┤
│ (AA)  Название чата           9:48 PM    │  строка 72dp
│       Превью последнего…        ( 2 )    │  аватар 56dp, отступ слева 12dp
├──────────────────────────────────────────┤
│ (BB)  Второй чат              9:30 PM    │
│       текст                              │
└──────────────────────────────────────────┘
                                   ( ✏️ )    FAB 56dp справа снизу
```

Строка списка — точно как в телеге:
- аватар 56dp круглый, по вертикальному центру строки
- название: 17dp, цвет `chats.name`, начинается на 16dp правее аватара, сверху 13dp
- время: 12dp, `chats.date`, прижато к правому краю с отступом 15dp, на одной линии с названием
- превью: 16dp, `chats.message`, ниже названия, одна-две строки с обрезкой
- имя отправителя в превью группы — цветом `chats.nameMessage`
- бейдж непрочитанных: круг 22dp, `chats.unreadCounter`, белая цифра, справа снизу
- если чат без звука — бейдж `chats.unreadCounterMuted`
- закреплённый чат — иконка булавки `chats.pinnedIcon` перед названием
- нажатие — фон `chats.selectedBackground`

### Экран чата

```
┌──────────────────────────────────────────┐
│ ←  (AA) Название                  56dp  │  шапка
│         был(а) недавно        [🔍] [⋮]   │
├──────────────────────────────────────────┤
│           ┌── 12 октября ──┐             │  плашка даты по центру
│                                          │
│ ┌────────────┐                           │  входящее: слева
│ │ текст  9:48│                           │  фон chat.inBubble
│ └────────────┘                           │
│                    ┌────────────┐        │  исходящее: справа
│                    │ текст 9:48 │✓✓      │  фон chat.outBubble
│                    └────────────┘        │
├──────────────────────────────────────────┤
│ [📎] [Написать...]            [🎤/➤]     │  панель ввода
└──────────────────────────────────────────┘
```

Пузырь:
- радиус 12dp, у первого сообщения серии — хвостик 8dp в сторону отправителя
- внутренние отступы 9dp по горизонтали, 7dp по вертикали
- максимум 78% ширины экрана
- текст 16dp `chat.messageTextIn` / `chat.messageTextOut`
- время 12dp в правом нижнем углу внутри пузыря: `chat.inTime` / `chat.outTime`
- галочки исходящих: `chat.sentCheck`, прочитано — `chat.sentCheckRead`
- в группах над текстом имя отправителя 14dp цветом `nameColorFor(senderId)`
- между сообщениями одного отправителя 2dp, между разными — 8dp
- аватар собеседника 32dp слева от входящих, отступ 8dp

Панель ввода:
- фон `composer.background`, минимальная высота 48dp
- слева кнопка скрепки 42dp цветом `composer.icons`
- поле ввода: текст `composer.text`, плейсхолдер `composer.hint`
- справа: если поле пустое — микрофон, если есть текст — кнопка отправки
- скругление поля 20dp

### Экран входа

По центру: крупно «67», ниже подпись, два поля (username/пароль), переключатель
вход/регистрация, большая кнопка акцентным `text.blue`. Всё на `windowBackground`,
поля — `composer.background`.

## Ограничения

1. **Никаких новых зависимостей.** Только то, что уже есть в `mobile/package.json`.
   Иконки — текстовые символы или простые `View`/`Text`, без векторных библиотек.
2. TypeScript. Типы пропсов описывать явно.
3. Не менять `api.ts`, `types.ts`, `crypto.ts`, `roomCrypto.ts`, `webrtc.ts`,
   `storage.ts`, `config.ts`, `format.ts`, `notifications.ts`.
4. Не трогать ничего вне папки `mobile/`.
5. `StyleSheet.create` в каждом компоненте, никаких инлайновых объектов стиля в JSX.
6. Сохранить всё существующее поведение: реакции, ответы, редактирование,
   удаление, пересылку, вложения, голосовые, видеокружки, звонки, профиль,
   сессии, смену пароля, выход.

## Критерий готовности

- `npx tsc --noEmit` в папке `mobile/` не выдаёт ошибок
- приложение собирается (`expo prebuild` + `gradlew assembleRelease` уже
  проверяются в CI, отдельно собирать не надо)
- экран списка чатов, чата и входа выглядят как описано выше
