# Иконки Messenger67

19 контурных символов созданы встроенным генератором изображений отдельно, с общей стилевой референцией и прозрачным фоном. Оригиналы сохранены в `source/`; PNG для React Native — 24, 48 и 72 пикселя (`@2x`, `@3x`).

`Icon.tsx` выбирает ресурс и задаёт цвет текущей темы. Пользовательские эмодзи и реакции остаются текстом.

Повторная упаковка размеров без генерации новых изображений: `npm run icons:prepare` из `mobile`. Скрипт использует sharp только для изменения размера готовых исходников и обновления реестра ресурсов.
