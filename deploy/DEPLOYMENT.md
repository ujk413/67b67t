## Исправления обмена сообщениями

WebSocket устанавливает обработчик до асинхронной авторизации, сериализует
приходящие кадры и не завершает корректную нативную сессию начальным
`auth.required`. В Android присоединение к комнате происходит после `auth.ok`;
зависшие HTTP/handshake-запросы ограничены временем ожидания.

Android 1.1.3 (versionCode 8) вычисляет PBKDF2-HMAC-SHA256 в нативном
фоновом модуле, сохраняя параметры 250000/256 и совместимость room-v2.
Сессия, SQLCipher-хранилище и очередь сохраняются при обновлении поверх APK.
В эмуляторе Android 11 проверены обновление с 1.1.2, прежняя история,
отправка, отключение сети, сохранение очереди после завершения процесса
и отправка после восстановления сети. Физический телефон пользователя
на Android 16 не подключён; исправление на нём нужно подтвердить.

Исправлена точность курсоров истории PostgreSQL: микросекунды больше
не теряются при сравнении с JavaScript Date. Последнее сообщение не
попадает снова в следующую страницу, отсутствует ложный `has_newer`.

Локальные проверки: 54 мобильных + 22 API/веб-теста, 2 JVM-теста нативного
PBKDF2, TypeScript. Release APK собрана с прежним сертификатом подписи:
`1a218f859a412f623104d83aaaad0a44abdad3ed665060ac8085902891dc9ab8`.
Текущая APK: `builds/67chat-1.1.4.apk`, также `builds/messenger67.apk`, SHA256:
`01698ecbca8a60d73b61902fba1e7ff3cc384bf31450e0243edae6b516111379`.
Клиентский JSON сохранён в GitHub Actions secret `ANDROID_GOOGLE_SERVICES_JSON`;
приватный ключ сервера в CI не загружается. Предыдущая APK 1.1.3 сохранена.

## Серверные проверки и резервные копии

`scripts/live_server_check.mjs` проверяет HTTPS, веб-сессию cookie,
мобильную bearer-сессию, capabilities, повторное открытие личного чата,
WSS-доставку, отсутствие дублей, границы истории, VAPID-конфигурацию,
запись/скачивание вложения и HMAC TURN credentials. Временные данные
скрипта удаляются по их точным ID; пользовательские аккаунты сохраняются.
Ранее отдельно проверены внешний STUN Binding и передача 10/10 пакетов
через TURN UDP и TCP. Звонки на двух реальных телефонах не проверялись.

Резервные копии PostgreSQL перед обновлениями находятся в
`/var/backups/messenger67/` (каталог 0700). Секреты сохранены там как
`environment.initial` и `environment.current` (0600), старый веб-клиент —
`web-before-redesign.tar.gz`. Нужны автоматические внешние копии, включая
`data/uploads`. Нагрузочное тестирование пока не проводилось.

Текущий архив: `builds/messenger67-server.tar.gz`, 62 исходных файла,
