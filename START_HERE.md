### Вариант 2: Ручная проверка

1. **Запустить:**
```bash
docker-compose up -d
```

2. **Открыть два браузера:**
   - Chrome обычный
   - Chrome инкогнито

3. **Зарегистрировать двух пользователей:**
   - user1 / password123
   - user2 / password123

4. **Начать DM чат:**
   - user1 → найти user2 → начать чат
   - Отправить "Hello!"

5. **Проверить в БД что зашифровано:**
```bash
docker exec messenger67-postgres psql -U messenger -d messenger -c "SELECT encrypted_content, meta FROM messages ORDER BY created_at DESC LIMIT 1;"
```

Должно быть:
- `encrypted_content` = JSON с зашифрованными данными
- `meta` = `{"e2e": true, "sender_device_id": "1"}`
- `text` = NULL

6. **Проверить в DevTools:**
```javascript
// Открыть Console
state.e2eReady  // должно быть true
state.e2eManager  // должен быть объект
```
