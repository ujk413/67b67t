# Полное Android приложение - План разработки

## Проблема с текущим Expo приложением

Текущее приложение использует Expo, но для ПОЛНОГО функционала нужно:
- ❌ ConnectionService (звонки из locked screen) - **не поддерживается в Expo**
- ❌ Фоновые сервисы - **ограничены в Expo**
- ❌ Нативные модули для VoIP - **требуют bare React Native**

## Решение: Создать bare React Native приложение

### Что будет:

1. **Bare React Native** (не Expo)
   - Полный доступ к нативным API
   - ConnectionService для звонков
   - Фоновые сервисы
   - VoIP push

2. **Все функции:**
   - ✅ Чаты, сообщения, группы
   - ✅ E2E шифрование
   - ✅ Голосовые звонки
   - ✅ Звонки из locked screen
   - ✅ Push уведомления (FCM)
   - ✅ Фоновая синхронизация

3. **Нативные модули:**
   - react-native-webrtc
   - react-native-callkeep (ConnectionService)
   - @react-native-firebase/messaging
   - @react-native-async-storage/async-storage
   - react-native-background-actions

## Важно понимать

**Звонки из locked screen как в WhatsApp/Telegram:**
- Требуют нативной разработки
- Нужны специальные разрешения Android
- Нужна интеграция с ConnectionService
- Это не делается за пару часов

**Expo ограничения:**
- Expo не поддерживает ConnectionService
- Нельзя сделать звонки как системные
- Это архитектурное ограничение Expo

**Поэтому:**
- Либо быстро с ограничениями (Expo)
- Либо долго но полностью (bare RN)
- Либо компромисс (гибрид)
