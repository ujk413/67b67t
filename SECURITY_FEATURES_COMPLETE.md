### 2. ✅ Session Management

**Функционал:**
- Список всех активных сессий пользователя
- Отображение устройства, IP, последней активности
- Завершение конкретной сессии
- Завершение всех остальных сессий
- Завершение всех сессий (logout everywhere)
- Автообновление last_activity при каждом запросе
- Парсинг User-Agent для определения устройства

**Безопасность:**
- Мониторинг всех активных входов
- Быстрая реакция на несанкционированный доступ

**База данных:**
- Миграция для добавления полей отслеживания

**API Endpoints:**

- `POST /auth/sessions/terminate-others` - завершить остальные
- `POST /auth/sessions/terminate-all` - завершить все

### 3. ✅ Safety Numbers (Key Verification)

**Функционал:**
- Генерация 60-значного кода безопасности
- Верификация ключей шифрования с собеседником
- Защита от MITM атак
- SHA-256 fingerprint из ключей обоих пользователей
- Копирование кода в буфер обмена
- Детальные инструкции по проверке

**Безопасность:**
- Детерминированная генерация из ключей обоих пользователей
- Уникальный код для каждой пары
- Изменяется при регенерации ключей
- Обнаруживает подмену ключей

**Как работает:**
1. Комбинирует identity keys обоих пользователей
2. Создает SHA-256 хеш
3. Конвертирует в 60-значное число (12 групп по 5)
4. Пользователи сравнивают коды через безопасный канал

**UI:**
- Панель с большим кодом
- Кнопка "🔐 Код безопасности" в профиле
- Инструкции по проверке
- Предупреждения о безопасности
- Технические детали (collapsible)

**Файлы:**
- `web/crypto.js` - метод `generateSafetyNumber()`
- `web/app.js` - UI панель
- `web/app.css` - стили

## 🚀 Как использовать

### 1. Бэкап ключей

```
1. Нажмите кнопку 🔑 в топбаре
2. Нажмите "🔑 Создать бэкап"
3. Скачайте файл или скопируйте
4. Храните в безопасном месте!
```

**Восстановление:**
```
1. Нажмите 🔑 → "📥 Восстановить из бэкапа"
2. Выберите файл бэкапа
3. Подтвердите восстановление
4. Перезагрузите страницу
```

### 2. Управление сессиями

```
1. Нажмите кнопку 📱 в топбаре
2. Просмотрите список активных устройств
3. Завершите подозрительные сессии
4. Или завершите все остальные
```

**Рекомендации:**
- Проверяйте сессии раз в неделю
- Завершайте неизвестные устройства
- После смены пароля завершите все сессии

### 3. Проверка Safety Number

```
1. Откройте профиль собеседника
2. Нажмите "🔐 Код безопасности"
3. Попросите собеседника сделать то же самое
4. Сравните коды через безопасный канал:
   - Лично
   - По телефону
   - Видеозвонок
5. Коды должны полностью совпадать!
```

**Когда проверять:**
- При первом общении
- После переустановки приложения
- Если код изменился без причины
- При подозрении на MITM атаку

## ⚠️ Важные предупреждения

### Бэкап ключей:

1. **Храните в безопасности**
   - Менеджер паролей (1Password, Bitwarden)
   - Зашифрованный диск
   - Физический носитель в сейфе

2. **НЕ храните:**
   - В облаке без шифрования
   - В email
   - В незашифрованных заметках
   - На скриншотах

3. **Помните:**
   - Любой с бэкапом может прочитать сообщения
   - Потеря бэкапа = потеря доступа к старым сообщениям
   - Создавайте бэкап после каждого важного разговора

### Session Management:

1. **Регулярно проверяйте**
   - Минимум раз в неделю
   - После поездок
   - После использования публичных компьютеров

2. **Завершайте сессии:**
   - На чужих устройствах
   - На старых устройствах
   - При подозрении на взлом

### Safety Numbers:

1. **Сравнивайте через безопасный канал**
   - НЕ через SMS
   - НЕ через email
   - НЕ через незашифрованный мессенджер

2. **Проверяйте регулярно**
   - При первом контакте
   - После смены устройства
   - Если код изменился
